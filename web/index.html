    00 / На телефоне

    Левый палец — джойстик в любом месте левой половины: влево/вправо — ходьба, вверх — прыжок (с наклоном — в сторону), вниз — присед. Два быстрых движения в сторону — рывок. Правый палец — кнопки: УДАР, НОГА, СИЛЬНЫЙ, БЛОК (держать). Пока джойстик опущен вниз, кнопки становятся низкими атаками: НИЗКИЙ, ПОДСЕЧКА, АППЕРКОТ — подписи меняются прямо на кнопках. Палец можно вести по кнопкам, не отрывая. Играть можно и вертикально, и горизонтально; кнопка ⛶ — во весь экран.

    01 / Атака и дистанция

    J — быстрый удар рукой, U — дальний удар ногой, K — мощный удар сверху, L — захват через блок. Из приседа (C): C + J — быстрый низкий удар ногой, C + U — подсечка, сбивает с ног, C + K — апперкот. W — прыжок, в воздухе U — удар ногой. A/D — движение, Space — рывок: вперёд — быстрое сближение без защиты, назад — уход, сквозь который удары проходят мимо.

    02 / Собирай связки

    Повторное нажатие одной кнопки продолжает серию разными ударами: J, J, J — джеб, кросс, хук; U, U — прямой и боковой удар ногой (боковой отбрасывает соперника к стене или в соседнюю комнату). Концовку выбираешь сам: J, J, U — удар с разворота сбивает с ног, J, J, K — апперкот при попадании. C + J → C + K: низкий удар → апперкот, соперник взлетает. После U нажми K для апперкота; после J можно перейти в K. Нажимай следующий удар в момент попадания. Даже в блок J → J и J → U продолжают давление, но перед медленным добивающим соперник может вклиниться. Длинная серия наносит меньше урона за каждый удар.

    03 / Читай высоту атаки

    S — верхний блок, C + S — нижний: против низкого удара и подсечки. Удар сверху K пробивает нижний блок, а C без блока позволяет уклониться от джеба. Апперкот C + K проходит сквозь прыжки и джебы, но после блока его наказывают. Свежий блок за миг до удара парирует; частое нажатие блока парирования не даёт. Блокирующего можно схватить L. Схватили тебя — сразу жми L (на телефоне — ВЫРВАТЬСЯ), чтобы сорвать бросок. После заблокированного сильного удара отвечай быстрым.

    04 / Стили бойцов

    Универсал — ровный набор, на нём удобно учиться. Напор — быстрый шаг и длинный рывок, который сразу переходит в удар или захват; быстрее вблизи, но ноги короче. Дистанция — боковой удар (U, U), разворот и импульс достают дальше, быстрее отходит; вплотную медленнее. Стиль подписан под бойцом в лобби.

    05 / Зоны попадания

    Удар попадает, если его зона касается тела или вытянутой руки и ноги соперника. Присев, уходишь под джеб; в прыжке — над подсечкой; промахнувшийся дальний удар можно наказать по ноге. В тренировке кнопка «Зоны» показывает их: зелёное — тело, жёлтое — вытянутая конечность, красное — удар, серое — габарит.

    06 / Энергия и выход из комбо

    Золотая шкала накапливается при попаданиях. I — мощный импульс за половину шкалы. При полной шкале нажми блок + рывок (на телефоне — ИМПУЛЬС) во время вражеской серии: оттолкни соперника и выйди из комбо. После падения есть короткое безопасное окно для подъёма, но атака сразу его снимает. Подброшенный соперник не может атаковать до приземления.

    07 / Бой по всей квартире

    Пять комнат соединены открытыми проходами: двигайся влево и вправо, чтобы перенести бой. Новые раунды начинаются в разных комнатах. Удары и отброшенное тело повреждают мебель; Q позволяет разбить предметы рядом без соперника. Внешние стены и пол остаются целыми. В тренировке переключай бота между спаррингом, манекеном и двумя видами блока.
