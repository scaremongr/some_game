# Настройка @somee_game_bot для PULSE

В этой папке всё, что нужно загрузить в BotFather:

| Файл | Куда |
|---|---|
| `avatar.jpg` (640×640) | фото профиля бота |
| `description.jpg` (640×360) | картинка в пустом чате с ботом («Что умеет этот бот?») |
| `preview-1.jpg`, `preview-2.jpg`, `preview-3.jpg` (720×1280) | превью Mini App в профиле бота |

Остальное (кнопка меню «Играть», команды `/start` и `/help`, текст описания,
короткое описание в профиле, ответ на `/start` с картинкой и кнопками) сервер игры
настраивает сам при каждом запуске, как только получит токен бота.

## 1. Токен бота → на сервер (один раз)

1. В Telegram откройте **@BotFather** → `/mybots` → **@somee_game_bot** → **API Token**.
2. Скопируйте токен (вида `123456789:AA…`) в файл `secrets/game-bot-token.txt`
   в папке проекта. Папка `secrets` никуда не отправляется и не попадает в сборку.
3. `python tools/set-game-bot-token.py` — проверит токен у Telegram (покажет только имя
   бота) и сохранит его на сервере в защищённый файл. Затем выкладка игры
   (`.\deploy.ps1`, `python scripts/publish.py`).

Токен не нужно присылать в чат: скрипт передаёт его прямо на сервер.

## 2. Главное Mini App (обязательно)

BotFather → `/mybots` → **@somee_game_bot** → **Bot Settings** → **Configure Mini App**
→ **Enable Mini App** → отправьте адрес:

```
https://serbiamarket.duckdns.org/dance/index.html
```

После этого:
- в профиле бота и в списке чатов появится кнопка **«Открыть»**, которая сразу запускает игру;
- ссылка **https://t.me/somee_game_bot?startapp=fight_home** открывает игру у любого
  пользователя Telegram;
- приглашения из кнопки «Вызвать друга» станут ссылками на этого бота
  (сервер переключится сам при следующей выкладке).

Там же, в **Configure Mini App**, можно добавить превью: **Edit Mini App Previews** →
`preview-1.jpg`, `preview-2.jpg`, `preview-3.jpg`.

## 3. Внешний вид

BotFather → `/mybots` → **@somee_game_bot** → **Edit Bot**:
- **Edit Botpic** → `avatar.jpg`;
- **Edit Description Picture** → `description.jpg`.

Описание и «О боте» трогать не нужно: сервер пишет их сам (правки в BotFather
перезапишутся при следующем запуске сервера).

## Группы и рейтинг чата

Бота можно добавить в любой групповой чат (в BotFather по умолчанию разрешено;
проверка: **Bot Settings → Allow Groups? → Turn on**). Прав администратора не нужно.
В чате: `/top` — таблица участников, `/join` или кнопка «➕ Я в таблице» — встать в таблицу,
`/leave` — выйти. Бои между участниками бот объявляет в чате сам.

## Как игроки запускают игру

- кнопка **«Играть»** слева от поля ввода в чате с ботом (кнопка меню);
- кнопка **«Открыть»** в профиле бота и в списке чатов (главное Mini App);
- команда `/start` — картинка игры и кнопки «Играть», «Вызвать друга», «Поделиться игрой»;
- ссылка https://t.me/somee_game_bot?startapp=fight_home — её можно разослать или поставить в канал;
- «Вызвать друга» в игре создаёт комнату и ссылку-приглашение; друг по ней попадает сразу в бой.

Барахолка (@srb_flea_market_bot) продолжает открывать игру по старым ссылкам.
